# Scholarly Library

This library holds papers, books, journals, and reference documents gathered from many disciplines and kept together in a single folder, with no division into sections. A file name begins with the title of the work, followed by the author and the year, so that a document can be identified from its name alone and the folder reads in alphabetical order of title. Defense Intelligence Agency reference documents begin with the prefix DIRD. [CATALOG.md](CATALOG.md) gives a short summary of each document.
